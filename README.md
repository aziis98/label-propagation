## Setup & Install

Requires [uv](https://docs.astral.sh/uv/) (Python 3.14+ is managed automatically via `.python-version`).

```bash
# Install dependencies into .venv
uv sync

# Launch JupyterLab or Notebook
uv run jupyter lab
# uv run jupyter notebook
```

Notebooks live in `notebooks/` (e.g. `notebooks/main.ipynb`).
